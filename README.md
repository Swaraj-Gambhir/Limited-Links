# Full-Stack HTML Folder Viewer

This project is a full-stack application that allows users to:

* Upload folders containing HTML sites.
* Generate 15-minute expiring links to view those pages.
* Authenticate via Microsoft account (Azure AD).
* Maintain logs of activity.

## Tech Stack

*   **Frontend**: Next.js, shadcn/ui, NextAuth.js
*   **Backend**: FastAPI, Redis, SQLite/PostgreSQL
